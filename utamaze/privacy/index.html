Utamaze! プライバシーポリシー

HALKAは、Utamaze!（うたまぜ！）の提供およびサポートに関連して取得する情報を、以下の方針に基づいて取り扱います。

1. 取得する情報

お問い合わせフォーム

Tally のお問い合わせフォームを通じて、次の情報を取得する場合があります。

  • 必須：お問い合わせ種別、返信先メールアドレス、お問い合わせ内容
  • 任意：Utamaze! のバージョン、使用しているDAW、Windows のバージョン、購入時のメールアドレス、ライセンスキーの末尾4文字 など

ライセンスキーの全文をお願いすることはありません。

購入

Lemon Squeezy でご購入いただいた場合、注文、購入者のメールアドレス、ライセンス等に関する情報のうち、購入の確認やサポートに必要な情報を、HALKAが確認できる場合があります。クレジットカード番号などの決済情報は Lemon Squeezy が取り扱い、HALKAがそれを受け取ったり保管したりすることはありません。

ライセンス認証

Utamaze! PRO の認証・状態の確認・認証の解除のときに、Lemon Squeezy の License API へ次の情報を送信します。

  • ライセンスキー
  • そのPC用にランダムに生成した識別子（Device ID）の一部から作る、匿名の名前（instance name。例：「Utamaze!-1A2B3C4D」）
  • 認証のときに Lemon Squeezy から発行される、そのPCの認証の番号（instance ID）

PC名、Windows のユーザー名、音声データ、DAWのプロジェクトは、ライセンス認証のために送信しません。

認証の状態は、そのPCの中に Windows の機能で暗号化して保存します。

アップデート確認

ユーザーがメニューの「アップデートを確認」を押したときだけ、Utamaze! 公式の version.json へアクセスします。

Utamaze! は、独自のテレメトリ（利用状況の収集）や、音声の解析データの送信を行いません。

なお、インターネット通信に通常伴う情報（IPアドレス等）は、通信先のサービスやホスティング事業者の側で取り扱われる場合があります。

2. 利用目的

取得した情報は、次の目的のために利用します。

  • お問い合わせへの回答
  • 購入の確認
  • ライセンス認証およびライセンスに関するサポート
  • 不具合の調査
  • 製品の改善
  • 不正利用の防止
  • 法令上必要な対応

取得した情報を、広告メールの送信や、第三者への販売のために利用することはありません。

3. 外部サービス

Utamaze! の提供のため、必要に応じて次の外部サービスを利用します。

  • Lemon Squeezy：決済、注文管理、ライセンス管理
  • Tally：お問い合わせフォーム
  • GitHub Pages：公式Webページのホスティング

各サービスにおける情報の取扱いについては、それぞれのサービスのプライバシーポリシー等が適用されます。

4. 第三者提供・委託

  1. 法令に基づく場合等を除き、取得した個人情報を、無関係な第三者へ提供または販売することはありません。
  2. サービスの提供に必要な範囲で、外部のサービス事業者へ情報の取扱いを委託する場合があります。

5. 保存期間

取得した情報は、お問い合わせやサポート等に必要な期間、および法令上必要な期間に限って保持し、不要となった情報は合理的な方法で削除または匿名化します。

6. 開示・訂正・削除等

ご本人から、ご自身の情報について確認、訂正、削除、利用停止等のご請求があった場合は、法令に従い、合理的な範囲で対応します。ご請求はお問い合わせフォームからお願いします。

7. 個人情報取扱事業者に関する情報

HALKA

氏名・住所等について法令上の開示が必要な場合は、ご本人からの求めに応じて遅滞なく回答します。お問い合わせフォームよりご請求ください。

8. セキュリティ

取得した情報について、不正アクセス、漏えい、紛失等を防止するため、合理的な安全管理措置を講じます。

9. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。重要な変更については、公式ページ等でお知らせします。
