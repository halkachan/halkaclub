# HALKA SITE EDITOR v0.1

halkaclub.com の中身を、HTMLを直接さわらずに書き換えるWindows専用アプリです。.NET 8 / WPF。

HTMLの構造は変えません。**値が入っている1か所だけ**を差し替えるので、前後の書き方・インデント・改行コードは元のまま残ります。

## できること（v0.1）

| タブ | 直せるもの | 書き込まれるファイル |
| --- | --- | --- |
| 依頼ページ | 受付状況、7項目の料金。**日本語版と英語版がとなり合わせ**で並びます | `commission/index.html`、`commission/en/index.html` |
| トップページ | 最新動画のURL（サムネイルがその場で出ます） | `script.js` |
| サイトの基本色 | 紙の白・外側の灰色・文字の黒・黄色・うすい文字・赤い縦線 | `style.css` |

料金の行にある「英語を合わせる」を押すと、日本語側の数字から `from 〇〇 JPY` を作って英語側へ入れます。英語版だけ直し忘れる事故を防ぐためのものです。

## 使いかた

1. `dist/win-x64/HALKA SITE EDITOR.exe` を起動します。EXEの近くにある halkaclub フォルダーを自動で探します。見つからないときは「フォルダーを選ぶ...」で指定してください（一度指定すると次回から覚えます）。
2. 直したい値を書き換えます。変えた欄は枠が黄色くなり、下の **変更一覧** に「変更前 → 変更後」が並びます。
3. 「保存する」でファイルに書き込みます。確認のダイアログが出ます。
4. ブラウザで確認します（`python -m http.server --directory <halkaclubのフォルダー>` など）。
5. 問題なければ **GitHub Desktop でコミット** します。公開されるのはこの時点です。

**このアプリは公開（push）をしません。** 保存はあくまで手元のファイルの書き換えです。公開ボタンはv0.4で付けます。

## 安全のための決まり

- **改行コードを変えません。** このリポジトリは `index.html` が CRLF、`style.css` が LF というように混在しています。値の前後に触れないので、差分は変えた行だけになります。
- **書き込みは一時ファイル経由**です。途中で落ちても元のファイルが壊れません。
- **読み込んだあとに別の場所でファイルが変わっていたら、保存を中止します。** VS Code で同じファイルを開いて直していたときに、片方の変更が消えるのを防ぐためです。読み込み直してからやり直してください。
- 入力に誤りがあると「保存する」が押せません。色は書き方（`#ffdc18` など）、動画URLはサイト側の `extractYouTubeId` と同じ判定、HTMLに入る文字は `< > &` を弾きます。
- 依頼ページの項目数が日本語版と英語版で食い違っていると、読み込み時に止まります。先にHTMLを揃えてください。

## 開発とテスト

```
dotnet build HalkaSiteEditor.sln -c Release
dotnet run --project HalkaSiteEditor.Tests -c Release
```

テストは本物のリポジトリを**読むだけ**で、書き込みの確認は毎回つくる一時フォルダーのコピーに対して行います。改行コードが変わらないこと、触っていないファイルが1バイトも変わらないこと、横から書き換えられていたら保存を中止することまで見ています。

配布用のEXEは PowerShell で `./scripts/publish-win-x64.ps1` を実行すると `dist/win-x64/` に出ます。自己完結版なので、.NETが入っていないPCでも動きます。

アプリアイコンは `HalkaSiteEditor/Assets/site-editor.ico`。変えるときは Pillow 入りの Python で `py scripts/generate-app-icon.py` を実行します。

この PC には .NET 8 ランタイムが無く 10 だけなので、`HalkaSiteEditor.csproj` に `<RollForward>Major</RollForward>` を入れてあります。`dotnet build` しただけのEXEも、これで起動します。
