はるかわーるど ver3.0 Release Candidate 2（ローカル版）
================================================================

これは公開前の確認用に、ローカルで動かす Release Candidate（RC2）です。
公開HP（halkaclub.com）、GitHub Pages、公開中の ver2.9 には何も反映していません。
RC1（HARUKA_WORLD_ver3.0_RC1）はそのまま残しています。

RC2 で新しくなったのは、セーブです。
「通常は完全自動。前回の続きから再開。もしものときはファイルから復元。」


1. 起動
-------
  start_rc2.bat をダブルクリックします（Python 3 が必要です）。
  サーバーが起動し、少しするとブラウザで次のページが開きます。

    http://127.0.0.1:8897/halkaworld/

  手動で起動する場合は、このフォルダで次を実行します。
    python serve_rc2.py

  止めるときは、黒いウィンドウで Ctrl+C を押すか、ウィンドウを閉じます。
  RC1（8895）とはポートが違うので、両方を同時に動かせます。保存データも別々です。


2. ページ
---------
  http://127.0.0.1:8897/halkaworld/
      ステージングページです。公開中のゲームページと同じレイアウト・CSSで、枠の中に RC2 が入っています。
  http://127.0.0.1:8897/halkaworld/webgl/
      ゲームだけの画面です。
  http://127.0.0.1:8897/halkaworld/webgl/?debug=1
      検証用パネルを表示します（DEBUG_RC2.txt）。


3. 遊び方（操作は今までと同じです）
-----------------------------------
  PC:     WASD・矢印キーで1マスずつ移動 / 対象をクリック
  スマホ: 十字キーで移動、Aボタンで正面を調べる（縦でも横でも遊べます）

  左上のメニュー（☰）:
    AUTO          自動で歩く（60秒操作しないと歩き出す）
    ひょうじ      2D / 3D の切り替え
    せいかつきろく 歩いた数・プレイ時間
    セーブデータ  エクスポート（ファイルに書き出す）/ インポート（ファイルから復元する）
    やめる        メニューを閉じる
    いちばん下に版（ver3.0 RC2）が出ます。

  全画面: ステージングページの、ゲームの枠の下にある「全画面にする」ボタン（ゲームの外にあります）。
    iPhone の Safari では「画面いっぱい表示」になります。下の「もどす」か、戻る操作で元に戻ります。


4. セーブ
---------
  - 自動でセーブします。セーブボタンはありません。
    セーブするのは、歩いた数、プレイ時間、朝夜、AUTO の ON/OFF、2D/3D、いる場所（マップ・マス・向き）です。
  - 次に開くと、最後にいた場所から続きます（家の中なら家の中から）。
  - 自動バックアップを 3 世代持っています。最新が壊れていても、前の世代から続けます。
  - ブラウザのデータを消すと、自動バックアップも消えます。
    大切な記録は「セーブデータ → エクスポート」でファイルに書き出して、別の場所に保管してください。
    書き出したファイルは「インポート」で戻せます（SAVE_EXPORT_IMPORT_GUIDE_RC2.md）。
  - ver2.9 のデータ（歩いた数・プレイ時間）は、同じ場所（/halkaworld/webgl/）なら自動で引き継ぎます。
    ver2.9 に戻しても読めるように、今までのキーにも同じ値を書いています。
  - 保存場所は、ページの場所（オリジンとパス）ごとに分かれています。
    この RC2（http://127.0.0.1:8897/...）のデータは、公開版や RC1 のデータとは別です。
  詳しい仕様: HARUKA_WORLD_SAVE_SYSTEM_SPEC.md


5. フォルダ
-----------
  start_rc2.bat                     起動（lan を付けると、同じWi-Fiのスマホからも開けます）
  serve_rc2.py                      ローカルサーバー（読み取りのみ）
  halkaworld/index.html             ステージングページ
  halkaworld/webgl/                 RC2 本体（WebGL）
  BUILD_INFO.txt                    ビルドの識別子・日時
  DEBUG_RC2.txt                     検証用パネルとセーブの開発用ログ
  VERIFICATION_SETTINGS_RC2.txt     RC2 の確定設定
  DEVICE_TEST_PROCEDURE_RC2.md      スマホ実機での確認手順（セーブの項目 S1〜S11）
  SAVE_EXPORT_IMPORT_GUIDE_RC2.md   エクスポート・インポートの使い方（遊ぶ人向け）
  HARUKA_WORLD_SAVE_SYSTEM_SPEC.md  セーブの仕様書
  PUBLISH_PROCEDURE_RC2.md          公開手順書（承認の後に使う。今回は実行していません）
  ROLLBACK_PROCEDURE_RC2.md         ver2.9 に戻す手順書
  HARUKA_WORLD_ver3.0_PHASE6_REPORT.md  Phase 6 のレポート


6. RC1 からの変更
-----------------
  - 自動セーブ・自動ロード（最後の場所・向き・2D/3D・AUTO から再開）
  - 自動バックアップ 3 世代、壊れたデータからの復旧
  - メニューに「セーブデータ」（エクスポート・インポート・もどる）と「やめる」
  - ver2.9 のデータの自動引き継ぎ（今までのキーも書き続ける）
  - 同じゲームを2つのタブで開いたとき、古いタブが新しい進行を上書きしない
  - そのほか（2D/3D、輪郭線、全画面、ソファー など）は RC1 と同じです。
    3D のﾊﾙｶﾁｬﾝは、まだ仮のブロック状モデルです。
