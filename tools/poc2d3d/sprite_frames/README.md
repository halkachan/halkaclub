# 2Dﾊﾙｶﾁｬﾝのコマを、4方向の絵から作る道具

2026-10-20 に、ユーザーが描き直した4方向の絵（`bases/`）から、2Dﾊﾙｶﾁｬﾝのすべてのコマを作りました。そのときの道具です。

| フォルダ・ファイル | 中身 |
|---|---|
| `bases/1.png` 〜 `4.png` | ユーザーの絵（1 正面、2 背中、3 右、4 左）。64×64。各アニメーションの基本のコマとして、1ピクセルも変えずに使う |
| `templates/` | 前の GIF と前の座る絵。動かし方の手本（何ピクセル沈むか、脚・腕・髪がどう動くか） |
| `jump_ops.json` | 前のジャンプの各コマの操作（どの行・列を足したり抜いたりしたか）を測ったもの |
| `gen_basic.py` | 待機（2コマ目）、振り向き、正面・背中の歩き、HP の GIF |
| `gen_side.py` | 右・左の歩き（髪の揺れ、腕の振り、踏み出しの脚） |
| `gen_jump.py` | ジャンプ（21コマ）。前の絵に当てはめると前のジャンプが出てくることを毎回確かめる |
| `gen_bench.py` | 座る絵（新しい頭と上半身 ＋ 前の座った脚） |
| `make_gifs.py` | GIF の書き出し（前と同じ時間・繰り返し）と、読み直しての確認 |
| `build_all.py` | 全部を作る。`--install` を付けると、ゲームのフォルダに入れる |
| `pix.py` | 絵を文字（1色1文字）で表示する。手で直すときの確認用 |

## 使い方

```
python build_all.py              （out/ と gifs/ にできる。ゲームは変わらない）
python build_all.py --install    （ゲームの SourceGifs と座る絵を入れ替え、import_gifs.py を実行）
```

`--install` の後にすること:

1. `tools/poc2d3d/player_sprite_sha256.txt` を新しい値にする。
2. `tools/poc2d3d/player_model_manifest.py` を実行する。
3. 検査（Phase 2.1・7 の絵の記録の確認）を実行する。
4. WebGL を作り直す。

## 絵をまた描き直すとき

`bases/` の4枚を置き換えて `build_all.py` を実行します。ただし、次の場合は道具の数値を見直してください。

- 新しい絵の脚の長さや手の位置が変わった場合（`gen_basic.py` の脚・手の列、`gen_side.py` の行の対応、`gen_jump.py` の `new_row`）
- 横の絵の髪や腕の位置が変わった場合

詳しくは `HARUKA_WORLD_ver3.0_2D_SPRITE_UPDATE_REPORT.md` を見てください。
