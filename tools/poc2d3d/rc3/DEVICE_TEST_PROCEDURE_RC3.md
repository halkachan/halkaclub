# はるかわーるど ver3.0 RC3 — スマホ実機での確認手順

- RC1 と RC2 は、ユーザーが実機で確認しました。RC2 は、Phase 7 の指示書で「問題なし」と報告されています。
- RC3 は RC2 と同じゲームに、次の変更を加えたものです。RC2 から悪くなっていないかを、実機で確認するときの手順です。
  - 正式モデルの登録（見た目は同じ）
  - 版の表示（ver3.0）
  - セーブが全部壊れたときの修正
  - 公開用のページ
- Phase 7 では、Claude は PC の Chrome でスマホを模擬して確認しただけです。実機では確認していません。

## 準備

1. PC とスマホを同じ Wi-Fi につなぎます（自宅など信頼できるネットワークだけで行ってください）。
2. RC3 フォルダで `start_rc3.bat lan` を実行します
   （コマンドプロンプトで `start_rc3.bat lan`、または `python serve_rc3.py --lan`）。
3. 黒いウィンドウに `phone (same Wi-Fi): http://192.168.x.x:8899/halkaworld/` と表示されます。
4. Windows のファイアウォールの確認が出たら「プライベート ネットワーク」だけ許可します。
5. スマホのブラウザでその URL を開きます。
6. 終わったら黒いウィンドウで Ctrl+C を押して止めます（同じ Wi-Fi の他の機器からも見えるため）。

注意: スマホでの保存データは `http://192.168.x.x:8899` の場所に保存され、公開版のデータとは別です。

### Phase 6: セーブ（新しく確認すること）

| # | 操作 | 期待すること |
|---|------|--------------|
| S1 | 数歩歩き、家に入り、3D にして、AUTO を OFF にしてから、ページを再読み込み | 家の中の同じマス、同じ向き、3D、AUTO OFF で始まる。歩数・プレイ時間がそのまま |
| S2 | ブラウザのタブを閉じて、もう一度開く | S1 と同じ（閉じる直前の数秒は残らないことがある） |
| S3 | ベンチやソファーに座ったまま再読み込み | 座っていた前のマスに立った状態で始まる |
| S4 | ☰ → セーブデータ → エクスポート | iPhone: ダウンロードの確認 →「ファイル」の「ダウンロード」に harukaworld_save_日時.json。Android: ダウンロードに保存。「ファイルを かきだしました。」 |
| S5 | 少し歩いてから ☰ → セーブデータ → インポート → S4 のファイル | 確認画面（ほぞんした日、あるいたかず、プレイじかん、ばしょ、ひょうじ）→ ふくげんする → S4 の時点に戻る |
| S6 | インポートの確認画面で「やめる」 | 何も変わらない |
| S7 | インポートでファイル選択を閉じる（キャンセル） | 前の画面に戻る。戻らないときは「もどる」 |
| S8 | 写真など json ではないファイルを選ぶ | 「この ファイルは よみこめません。」。今のデータはそのまま |
| S9 | S4・S5 を、縦・横、全画面（Android）、画面いっぱい表示（iPhone）でも | どれでも同じように使える。うまくいかなければ全画面をやめて試す |
| S10 | 2つのタブで同じページを開き、片方で歩いてからもう片方で歩く | あとのタブに「べつの タブで セーブされました。…」。最初に歩いたタブのデータが残る |
| S11 | パソコンでエクスポート → スマホでインポート（ファイルを移して） | パソコンの続きから遊べる（置き換え。合算はされない） |
