はるかわーるど ver3.0 Release Candidate 3（ローカル版）
================================================================

これは公開前の最終確認用に、ローカルで動かす Release Candidate（RC3）です。
公開HP（halkaclub.com）、GitHub Pages、公開中の ver2.9 には何も反映していません。
RC1・RC2（HARUKA_WORLD_ver3.0_RC1 / _RC2）はそのまま残しています。

RC3 は「このまま公開できる形」にしたものです。
  - ゲームの中の版の表示は ver3.0 です（公開後にプレイヤーが見る表示）。RC3 という名前は、このフォルダ、
    BUILD_INFO.txt、ステージングページの帯、検証用パネル（?debug=1）にだけ出ます。
  - 3D のﾊﾙｶﾁｬﾝ（ブロック状のローポリ）は、正式な3Dモデルになりました（HARUKA_WORLD_PLAYER_MODEL_SPEC.md）。
    見た目は RC2 と同じです。
  - 2D のﾊﾙｶﾁｬﾝのドット絵は、ユーザーが描き直した4方向の絵をもとに、全部作り直しました（2026-10-20。
    待機・歩き・振り向き・ジャンプ・座る絵。HARUKA_WORLD_ver3.0_2D_SPRITE_UPDATE_REPORT.md）。
  - 公開用のゲームページ（release/halkaworld/）を用意しました。公開はしていません。


1. 起動
-------
  start_rc3.bat をダブルクリックします（Python 3 が必要です）。
  サーバーが起動し、少しするとブラウザで次のページが開きます。

    http://127.0.0.1:8899/halkaworld/

  手動で起動する場合は、このフォルダで次を実行します。
    python serve_rc3.py

  止めるときは、黒いウィンドウで Ctrl+C を押すか、ウィンドウを閉じます。
  RC1（8895）・RC2（8897）とはポートが違うので、同時に動かせます。保存データも別々です。
  スマホで開くとき: start_rc3.bat lan（同じ Wi-Fi のときだけ。DEVICE_TEST_PROCEDURE_RC3.md）


2. ページ
---------
  http://127.0.0.1:8899/halkaworld/
      ステージングページです。公開予定のゲームページ（release/halkaworld/index.html）と同じ内容で、
      枠の中に RC3 が入っています（検索に出ない設定、アクセス解析なし、上に黄色の帯）。
      更新履歴の ver3.0 の日付は「公開日」と表示しています（公開日が決まってから入れます）。
  http://127.0.0.1:8899/halkaworld/webgl/
      ゲームだけの画面です。
  http://127.0.0.1:8899/halkaworld/webgl/?debug=1
      検証用パネルを表示します（DEBUG_RC3.txt）。


3. 遊び方（今までと同じです）
-----------------------------
  PC:     WASD・矢印キーで1マスずつ移動 / 対象をクリック、または正面を向いて A キー
  スマホ: 十字キーで移動、Aボタンで正面を調べる（縦でも横でも遊べます）

  左上のメニュー（☰）:
    AUTO          自動で歩く（60秒操作しないと歩き出す）
    ひょうじ      2D / 3D の切り替え
    せいかつきろく 歩いた数・プレイ時間
    セーブデータ  エクスポート（ファイルに書き出す）/ インポート（ファイルから復元する）
    やめる        メニューを閉じる
    いちばん下に版（ver3.0）が出ます。

  全画面: ゲームの枠の下にある「全画面にする」ボタン（ゲームの外）。
    iPhone の Safari などでは「画面いっぱい表示」になります。下の「もどす」か、戻る操作で元に戻ります。


4. セーブ（RC2 と同じ仕様です）
-------------------------------
  - 自動でセーブします。次に開くと、最後にいた場所から続きます。
  - 自動バックアップを 3 世代持っています。最新が壊れていても、前の世代から続けます。
  - すべてのセーブが壊れていて、ほかに頼れるデータもないときは、セーブを止めて
    「セーブデータを よみこめませんでした。」と出します（約6秒）。その後、メニューの
    「セーブデータ → インポート」で、書き出しておいたファイルから戻せます。
    RC3 では、この状態で遊び続けても、次の起動でほぼ空のセーブを始めないようにしました。
  - ver2.9 のデータは、同じ場所（/halkaworld/webgl/）なら自動で引き継ぎます。
  詳しい仕様: HARUKA_WORLD_SAVE_SYSTEM_SPEC.md

6. RC2 からの変更
-----------------
  - 3D のﾊﾙｶﾁｬﾝを正式モデルとして登録（見た目・動きは変えていません）
  - ゲーム内の版の表示を ver3.0 に（公開するものと同じ Build）
  - すべてのセーブが壊れた状態で遊び続けたとき、次の起動で空に近いセーブを始めてしまう問題を修正
  - 公開用のゲームページ（名前、版、全画面ボタン、あそびかた、更新履歴 ver3.0）を用意
  - 2D のﾊﾙｶﾁｬﾝのドット絵を、ユーザーが描き直した4方向の絵で作り直し（2026-10-20。動き方は前と同じ）
  - そのほか（2D/3D、輪郭線、セーブ、全画面、ソファー など）は RC2 と同じです。
