# はるかわーるど セーブデータの書き出しと復元（ver3.0 RC2）

## ふだんは何もしなくて大丈夫です

- はるかわーるどは、遊んでいる間に**自動でセーブ**します。
- 次に開くと、**最後にいた場所から**つづきます（2D/3D、AUTO の ON/OFF、歩いた数、プレイ時間、朝夜も）。
- セーブのボタンやロードのボタンはありません。

## もしものための「エクスポート」

セーブデータは、このブラウザの中に保存されています。次のようなときに消えることがあります。

- ブラウザの「サイトデータの削除」をしたとき
- 端末を替えたとき
- 容量が足りなくなったとき

大切な記録は、ときどきファイルに書き出して、別の場所（パソコンのフォルダ、クラウドなど）に保管してください。

1. 左上の **☰** → **セーブデータ** → **エクスポート**
2. `harukaworld_save_YYYYMMDD_HHMMSS.json` という名前のファイルがダウンロードされます。
   - **PC**: ダウンロードフォルダ
   - **Android（Chrome）**: ダウンロード
   - **iPhone（Safari）**: 「ダウンロード」の確認が出るので「ダウンロード」を押します。「ファイル」アプリの「ダウンロード」に入ります。
3. 「ファイルを かきだしました。」と出たら完了です。

エクスポートしても、ゲームの中は何も変わりません。

## 「インポート」で元に戻す・別の端末へ移す

1. ☰ → **セーブデータ** → **インポート**
2. ファイルを選ぶ画面で、書き出しておいた `.json` を選びます。
3. 確認画面が出ます。内容（ほぞんした日、あるいたかず、プレイじかん、ばしょ、ひょうじ）を確かめます。
4. **ふくげんする** を押すと、そのファイルの時点に置き換わります。やめるときは **やめる** を押します。
5. 「セーブデータを ふくげんしました。」と出たら完了です。ファイルに保存されていた場所から続きます。

**大事なこと**

- インポートは**置き換え**です。今の歩数に足されるのではなく、ファイルの歩数になります。
- 壊れたファイルや、ほかのゲームのファイルは読み込みません。そのときは今のセーブはそのままです。
- インポートの直前の状態は、ゲームの中に1つ控えてあります。

## こんな表示が出たら

| 表示 | 意味 |
|---|---|
| セーブデータを ふくげんしました。 | 最新のセーブが読めなかったので、ひとつ前の自動バックアップから続けています |
| セーブデータを よみこめませんでした。 | 自動バックアップも読めませんでした。エクスポートしたファイルがあれば、セーブデータ → インポートで戻せます |
| あたらしい ばんの セーブデータです。この ばんでは セーブしません。 | もっと新しい版で保存されたデータです。消さないように、この版では保存しません |
| べつの タブで セーブされました。この タブでは セーブしません。 | 同じゲームを別のタブでも開いています。どちらか1つのタブで遊んでください（続けるタブを再読み込み） |

## うまくいかないとき

- **ファイルを選ぶ画面が出ない**: 全画面や画面いっぱいの表示を、いったんやめてから試してください。
- **ファイルを選ぶ画面を閉じた後、「ファイルを えらんでください。」のまま**: 「もどる」を押してください。
