# はるかわーるど ver3.0 RC1 — スマホ実機での確認手順

Phase 5 では実機のスマホを使えなかったため、PC の Chrome でスマホを模擬して確認しました。
ここに書いたことは **実機ではまだ確認していません**。実機で確認するときの手順です。

## 準備

1. PC とスマホを同じ Wi-Fi につなぎます（自宅など信頼できるネットワークだけで行ってください）。
2. RC1 フォルダで `start_rc1.bat lan` を実行します
   （コマンドプロンプトで `start_rc1.bat lan`、または `python serve_rc1.py --lan`）。
3. 黒いウィンドウに `phone (same Wi-Fi): http://192.168.x.x:8895/halkaworld/` と表示されます。
4. Windows のファイアウォールの確認が出たら「プライベート ネットワーク」だけ許可します。
5. スマホのブラウザでその URL を開きます。
6. 終わったら黒いウィンドウで Ctrl+C を押して止めます（同じ Wi-Fi の他の機器からも見えるため）。

注意: スマホでの保存データは `http://192.168.x.x:8895` の場所に保存され、公開版のデータとは別です。

## 確認すること（記録用の表は最後）

| # | 操作 | 期待すること |
|---|------|--------------|
| 1 | 縦向きでステージングページを開く | ページが表示され、ゲームの枠の中に「スマホを横向きにしてください」が出る。ゲームは止まっている |
| 2 | 横向きにする | 案内が消えてゲームが動く。十字キーとAボタンが見える |
| 3 | 横向きで画面全体を見る | 公開ページと同じレイアウト（index.html）では枠が画面より高く、上下が切れることがある（既知）。index-mobilefix.html では枠が画面の高さに収まる |
| 4 | 十字キーで歩く | 1マスずつ動く。1歩ごとに足音（最初にどこかを触った後から音が出ます。iPhone はマナーモードだと鳴らないことがあります） |
| 5 | 草の上を歩く（2D） | 足元が草に隠れ、草が揺れる |
| 6 | Aボタン | 正面を調べる。看板・花・ベンチなど |
| 7 | ベンチ・家のクッション | Aで座る、もう一度Aで立つ。座っている間は歩かない |
| 8 | カラスに話しかける | 「カァ。」と声が1回 |
| 9 | 左上メニュー →「ひょうじ」 | 2D / 3D が切り替わる。位置・向き・座っている状態はそのまま |
| 10 | 3D で歩く | 十字キーの上が画面の奥（北）。カメラは回らない |
| 11 | 家に入って出る（3D） | 出た直後に家の正面が見える。十字キーを押したままなら0.6秒後に歩き続ける |
| 12 | 60秒何もしない | AUTO で歩き出す。触ると止まる |
| 13 | メニュー →「せいかつきろく」 | 歩数が増えている |
| 14 | 横向きのまま縦→横→縦→横 | 毎回、案内とゲームが正しく切り替わる。画面が拡大されたままにならない |
| 15 | ノッチ・角丸のある機種 | ボタンや文字がノッチ・ホームバーに隠れない |
| 16 | ページを再読み込み | せいかつきろくの歩数が残っている |
| 17 | 10分ほど遊ぶ | 動きが重くならない。本体が熱くなりすぎない |
| 18 | ページを上下にスクロール | ゲームの枠の上で十字キーを触ってもページがスクロールしない（index-mobilefix.html） |
| 19 | 全画面 | ゲームにも公開ページにも全画面ボタンはありません（ボタンは増やさない方針）。ブラウザの機能で全画面にした場合だけ確認 |
