# はるかわーるど ver3.0 RC1 — スマホ実機での確認手順

Phase 5 では実機のスマホを使えなかったため、PC の Chrome でスマホを模擬して確認しました。
ここに書いたことは **実機ではまだ確認していません**。実機で確認するときの手順です。

## 準備

1. PC とスマホを同じ Wi-Fi につなぎます（自宅など信頼できるネットワークだけで行ってください）。
2. RC1 フォルダで `start_rc1.bat lan` を実行します
   （コマンドプロンプトで `start_rc1.bat lan`、または `python serve_rc1.py --lan`）。
3. 黒いウィンドウに `phone (same Wi-Fi): http://192.168.x.x:8895/halkaworld/` と表示されます。
4. Windows のファイアウォールの確認が出たら「プライベート ネットワーク」だけ許可します。
5. スマホのブラウザでその URL を開きます。
6. 終わったら黒いウィンドウで Ctrl+C を押して止めます（同じ Wi-Fi の他の機器からも見えるため）。

注意: スマホでの保存データは `http://192.168.x.x:8895` の場所に保存され、公開版のデータとは別です。

## 確認すること（記録用の表は最後）

| 1 | 縦長のままステージングページを開く | ページが表示され、枠の中でゲームが動く（回転の案内は出ない） |
| 2 | 十字キーで歩く | 1マスずつ動く。1歩ごとに足音（最初にどこかを触った後から音が出ます。iPhone はマナーモードだと鳴らないことがあります） |
