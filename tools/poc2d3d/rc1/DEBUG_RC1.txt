はるかわーるど ver3.0 RC1 — 検証用パネル（デバッグ）
====================================================

通常のページでは表示されません（パネルの部品ごと止めているので、描画の負担もありません）。
URL の最後に ?debug=1 を付けると表示されます。

  http://127.0.0.1:8895/halkaworld/webgl/?debug=1
  スマホのタッチ表示をPCで見る: ?debug=1&touchControls=1

右上に「はるかわーるど ver3.0 RC1 (debug)」と出ていれば検証モードです。

パネルの項目（上から）
  VIEW                     2D / 3D の切り替え（メニューの「ひょうじ」と同じ）
  POC options: show/hide   以下の項目の表示
  2D pixels/cell           2D の1マスの画素数（RC1 は 16）
  2D camera pitch          2D の見下ろし角度
  2D square ground         地面を正方形にする補正
  3D keys                  3D のキーの意味（B camera-relative が標準）
  3D indoor cam            家の中のカメラ（closer+clamp が標準）
  Time                     real（実時間）/ force morning / force night
  Grid/blocked             マス目と通れないマスの表示
  Stats                    FPS・フレーム時間・Draw Calls・SetPass・三角形数・メモリ
  3D cam follow            3D カメラ（North fixed が標準）
  2D outline / Outline color / Grass outline / Inner lines   2D の輪郭線（1px #252B39 が標準）
  2D see-through trees     2D の木の透け
  3D indoor walls          家の中の壁の切り取り
  3D see-through trees     3D の木・イーゼルの透け（40%、0.25秒）
  3D exit camera           家から出た直後の構図（house front が標準）
  3D cam distance          3D カメラの距離（屋外 3.4 / 屋内 3.6）
  3D exit held key         家から出るときキーを押したままの場合
                             walks on after 0.6s … 家を0.6秒見せてから、そのまま歩き続ける（標準・正式）
                             waits for release (Phase 4) … 一度キーを離すまで止まる（比較用）
  2D grass                 2D の草（3D tufts (Phase 4) が標準 / 2D game sprites は比較用）
  3D outline               3D の輪郭線（ON が標準）

パネルの設定は保存されません（再読み込みで標準に戻ります）。
