あそびかた

パソコン
WASD・矢印キーで1マスずつ歩きます。近くのものをクリックすると、調べたり座ったりできます。3D では、ﾊﾙｶﾁｬﾝをクリックすると正面のものを調べます。
スマホ
十字キーで歩き、A ボタンで正面を調べます。縦向きでも横向きでも遊べます。
2D と 3D
左上の ☰ メニューの「ひょうじ」で、ドット絵の 2D と、立体の 3D を切り替えられます。どちらも同じ世界です。
全画面
ゲームの下の「全画面にする」で大きく遊べます。iPhone などでは画面いっぱいに広がり、下の「もどす」で元に戻ります。
セーブ
セーブは自動です。次に開いたときは、前回いた場所から続きます。セーブは、このブラウザの中に保存されます。
バックアップ
☰ メニューの「セーブデータ」から、セーブをファイルに書き出す（エクスポート）・ファイルから戻す（インポート）ことができます。ブラウザのデータを消す前や、ほかの端末で続きを遊びたいときに使ってください。

ブラウザのサイトデータを消したり、プライベートブラウズで遊んだりすると、セーブは残りません。同じゲームを2つのタブで開いたときは、あとからセーブしたタブのデータが残ります。
